## 3. Cara Menjalankan Program

1. Aktifkan Apache pada XAMPP.
2. Simpan folder praktikum di `htdocs`.
3. Buka browser.
4. Akses `http://localhost/Lab7Web_PHP/index.php`.

## 6. Pengujian Validasi

Data valid:
- Nama dan program studi diisi.
- Harga berupa angka.
- Jumlah minimal 1.
- Email sesuai format.
- Semester 1 sampai 14.

Data tidak valid:
- Nama dikosongkan.
- Harga diisi huruf.
- Jumlah bernilai 0.
- Email salah format.
- Semester di luar rentang.
- NIM tidak sesuai format.
